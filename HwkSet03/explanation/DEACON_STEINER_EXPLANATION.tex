	This program was relatively easy to adapt. I used pattern matching along with filter to make \texttt{sumIt} a very functional solution to this problem. I use a parity parameter to determine whether the function should sum the whole list (parity = 0) the evens (parity = 1) or the odds (parity = 2). I do the split using \texttt{filter} which is a very functional way to build a sublist that follows the needed criteria.
